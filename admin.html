How to get your access token (one time)
  1. On GitHub: your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories and pick your site repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate it, copy it and paste it below. Never share it.
The token is saved only in this browser.
